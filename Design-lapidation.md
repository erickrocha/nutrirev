# Design System — Lapidation Clinic

## 1. Conceito Visual
Estética clínica premium/"quiet luxury": tons neutros terrosos, tipografia geométrica
enxuta, muito espaço em branco e imagens 3D abstratas (corpo humano em render
low-poly/faceted) com padrões de linhas geométricas (diamantes) como elemento gráfico
de fundo. Remete a joalheria (lapidação de pedras) aplicada ao corpo humano.

## 2. Paleta de Cores

| Uso | Cor aproximada | Observação |
|---|---|---|
| Fundo principal (hero/seções claras) | `#F7F1E8` (creme/marfim) | Fundo dominante do site |
| Fundo seções alternadas | `#FFFFFF` / `#FDFBF7` | Contraste sutil entre seções |
| Fundo seção destaque escura | `#8B7D6A` (taupe/marrom acinzentado) | Seção "Metodologia/Além dos Procedimentos" |
| Texto principal (headings) | `#2B2723` (quase preto, tom quente) | Alto contraste, sem ser preto puro |
| Texto secundário/body | `#8C8378` (cinza-marrom médio) | Parágrafos e subtítulos |
| Acento primário (botões, links ativos) | `#8B7355` (marrom dourado/taupe) | Botão "Iniciar Diagnóstico", item de nav ativo |
| Borda/outline | `#D8CFC0` (bege claro) | Botões secundários outline |
| Badge/pill background | `#EFE8DC` | Fundo de tags como "SOBRE NÓS" |

Não há cores vibrantes/saturadas — a paleta é inteiramente neutra e terrosa, reforçando
a sensação premium/clínica.

## 3. Tipografia
- Fonte geométrica sans-serif (formas circulares em "O"/"A", estilo Poppins/Jost/Century
  Gothic).
- Headings principais (hero, títulos de seção): caixa alta, peso leve/regular, com
  letter-spacing amplo (ex: "SEU CORPO NÃO PRECISA MUDAR, PRECISA SER LAPIDADO").
- Subtítulos e h2/h3 de conteúdo: caixa normal, peso regular a medium (ex: "Nossa
  Filosofia").
- Corpo de texto: peso leve (light/regular), cor secundária, line-height generoso.
- Labels/badges/nav: caixa alta, tamanho pequeno, letter-spacing bem amplo (tracking).

## 4. Componentes de UI

### Botões
- Primário: pill/rounded (border-radius alto), fundo sólido marrom-taupe, texto branco,
  ícone de seta à direita.
- Secundário: mesmo formato pill, sem fundo (outline fino bege), texto escuro, ícone de
  seta.

### Badges/Tags
- Pill pequeno, fundo bege claro, texto uppercase com tracking largo e cor secundária
  (ex: "SMART FORMULATIONS", "SOBRE NÓS").

### Cards
- Fundo levemente acinzentado/off-white, cantos arredondados, ícone circular de linha
  fina no topo, título, descrição curta, link "Ver detalhes →".

### Ícones
- Estilo line-art fino, dentro de círculos com fundo sutil.

## 5. Layout & Espaçamento
- Hero centralizado, com muito respiro vertical.
- Seções alternam fundo claro / fundo escuro (taupe) para criar ritmo visual.
- Grid de 2-3 colunas para cards de produtos/protocolos.
- Header fixo, com logo à esquerda, nav central, CTA de telefone (pill escuro) à direita.
- Footer em 3 colunas (Institucional / Protocolos / Contato) + logo e tagline.

## 6. Imagens & Gráficos
- Render 3D abstrato de corpo humano em tom monocromático creme/dourado (baixa
  poligonagem, efeito "faceted"/lapidado — reforça o conceito da marca).
- Padrões de linhas formando diamantes/facetas no fundo do hero, em traço muito fino.

## 7. Logo
- Ícone de diamante/gema (line art) acima do wordmark.
- Wordmark "LAPIDATION" em caixa alta com tracking largo, "CLINIC" abaixo em tamanho
  menor.

## 8. Tom de Voz (refletido no visual)
Frases de impacto curtas e diretas ("Seu corpo não precisa mudar. Precisa ser
lapidado."), unindo linguagem de bem-estar/saúde com metáfora de joalheria/lapidação.
